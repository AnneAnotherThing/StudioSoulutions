The quickstart

The whole product, in bullets.

Every address below points at The Beauty Collective, the demo building, so scenarios can be walked end to end without touching a live building. Every building gets its own copy of each piece; the last box names where Salon Plus runs it all today. The rollout carries the deep how-tos.

The app /a/demo

  • Search by studio, person, service, or suite
  • Filters: categories, Open now (runs on real hours), Available now
  • Cards: photos, bio, Call, Text, Book, socials
  • Specials show where people look: tag on the row, banner on the profile, plus the Specials tab
  • The map: tap a suite, or "Show me on the map" from any card
  • Claim button on unclaimed cards recruits tenants
  • Installs like an app: Add to Home Screen

Getting a studio on /join/?building=The Beauty Collective

  • Two minutes on a phone, from their own suite
  • Day chips compose the hours; hours power Open now
  • Bio choice: Write it for me, or Use my words
  • Up to four photos; instant receipt email
  • Publish from the Inbox; the welcome email delivers the code and a one-tap edit link

The studio portal /portal/?b=demo

  • Sign in: suite + code, or the welcome email's Edit your card button
  • Every studio has a code; the level only decides fields
  • Edits go live on save; every edit emails a before-and-after
  • Offers: composed from safe pieces, blanket when no services, one live per studio, Take it down any time
  • Send a question / Report a problem land flagged in the Inbox
  • Old change links and the Already listed? buttons all end here

The admin panel /leads · passcode · pick The Beauty Collective

  • Studios: card or sheet view, Center column, Hide, Delete, portal code with New code, the write-the-bio button
  • Inbox: publish sign-ups, answer questions, delete any record
  • Offers: every building, Hide switch
  • Buildings: each center's numbers; add a center here
  • Settings: the level switches and the mail test
  • Changes: who changed what, when

The live building everything above, running today

  • Salon Plus Studios has every piece live: the app at /salonplus/app, the studios' portal at /salonplus/offer
  • The owner hub at /laura: every link, live counts, copy-paste texts; it updates itself with every change
